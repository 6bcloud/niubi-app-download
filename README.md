# niubi app download

这里提供牛逼客户端各平台安装包下载。

## 最新版本

客户端当前版本为 `v1.2.2`。请进入本仓库的 Releases 页面，下载对应平台的安装包。

## 文件说明

### Windows

- `niubi-1.2.2-windows-x64-setup.exe`：Windows x64 安装版
- `niubi-1.2.2-windows-arm64-setup.exe`：Windows ARM64 安装版

### macOS

- `niubi-1.2.2-macos-arm64.dmg`：Apple Silicon 安装包
- `niubi-1.2.2-macos-amd64.dmg`：Intel 安装包

### Linux

Linux 安装包继续使用独立的 `v4.2.0` Release。

### Android

- `niubi-1.2.2-android-universal.apk`：Android 通用版
- `niubi-1.2.2-android-arm64-v8a.apk`：Android 64 位 ARM 版
- `niubi-1.2.2-android-armeabi-v7a.apk`：Android 32 位 ARM 版

### Android TV

- `niubi-1.2.2-android-tv-arm64-v8a.apk`：Android TV 64 位 ARM 版
- `niubi-1.2.2-android-tv-armeabi-v7a.apk`：Android TV 32 位 ARM 版

## 校验文件
