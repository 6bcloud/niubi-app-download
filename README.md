# niubi app download

这里提供牛逼客户端各平台安装包下载。

## 下载方式

请进入本仓库的 Releases 页面，下载对应平台的安装包。

## 文件说明

### Windows

- `niubi-3.7.8-windows-amd64.zip`：Windows 免安装版

### macOS

- `niubi-3.7.8-macos-universal.dmg`：macOS 安装包
- `niubi-3.7.8-macos-universal.zip`：macOS 压缩包

### Linux

- `niubi-3.7.8-linux-amd64.AppImage`：Linux AppImage
- `niubi-3.7.8-linux-amd64.deb`：Debian / Ubuntu
- `niubi-3.7.8-linux-amd64.rpm`：RedHat / Fedora / CentOS

### Android

- `niubi-mobile-universal.apk`：Android 通用版
- `niubi-mobile-arm64-v8a.apk`：Android arm64 设备
- `niubi-mobile-armeabi-v7a.apk`：Android 32 位 ARM 设备

### Android TV

- `niubi-tv.apk`：Android TV 版本

### 软路由

- `luci-app-mihomo_3.7.8_all.ipk`：OpenWrt LuCI 管理界面
- `mihomo_3.7.8_aarch64_generic.ipk`：OpenWrt aarch64
- `mihomo_3.7.8_arm_cortex-a7.ipk`：OpenWrt arm cortex-a7
- `mihomo_3.7.8_x86_64.ipk`：OpenWrt x86_64

## 校验文件

Release 中会附带 `checksums.txt`，可用于核对下载文件是否完整。
